# 农业视觉黄金场景

## 场景定义

黄金场景以“复杂农业环境中的目标检测、计数或病害分类研究”为主线，逐步验证 ScholarTrace 能否把一个模糊想法转化为可追溯科研证据链：

```text
研究问题 → 文献与证据 → 管线与采集方案 → 算法候选 → 实验 → 图表 → 论文 → 交付与现场验证
```

项目当前提供三个合成、脱敏的项目描述：

- 荔枝病虫害目标检测；
- 果园果实目标计数；
- 作物叶片病害分类。

它们覆盖了遮挡、小目标、重复观测、背景变化、数据泄漏和拒识等农业视觉问题，但不包含真实图像、论文、个人信息、实验日志、指标或现场结论。

## M0 验收用途

Fixture 用于验证：

- 项目包能够在 Python 3.12+ 环境安装；
- 项目描述满足固定 Schema；
- 至少三个项目 ID 唯一；
- 所有 Fixture 明确标记为 `synthetic_deidentified_fixture`；
- 所有 Fixture 明确拒绝真实场景验证声明；
- 机器相关绝对路径和未知字段会被拒绝。

运行：

```bash
uv run python scripts/validate_fixtures.py
```

预期输出只报告通过校验的 Fixture 数量和 ID，不报告任何模型能力或科研指标。

## 后续里程碑关系

M1 使用 `research-question.json` 在独立进程中验证可恢复的研究问题图。该文件仍是合成、脱敏的结构化输入，不是研究证据或真实果园结果。M3–M4 才引入真实文献和证据；M7–M10 才能形成经验证的指标、图表和论文草稿；M12 的真实场景验证必须使用另行提供且获授权的数据、设备和现场记录。
