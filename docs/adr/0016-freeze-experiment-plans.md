# ADR 0016：实验计划冻结后才能作为 Run 输入

- 状态：已接受
- 日期：2026-08-11
- 范围：M7.1 ExperimentPlan 与实验矩阵

## 背景

如果实验运行可以直接读取不断修改的草案，结果就无法回答“这次运行按哪个假设、数据版本、代码和配置执行”。M6 已经提供算法验证入口，M7 需要把它变成不可含糊的实验计划。

## 决策

- `ExperimentPlan` 保存假设、数据版本、代码 SHA、环境锁、配置引用、种子、重复次数、基线、候选、消融、指标和停止条件。
- 计划首先以 `draft` 保存；只有算法已批准且指定候选为 `approved_for_experiment` 时才能变为 `frozen`。
- 冻结版本不被覆盖；修改必须创建递增版本并填写父计划 ID，旧版本变为 `superseded`。
- 矩阵行与计划一起保存，保证方法、数据版本、配置、种子和指标协议处于同一个 canonical payload。
- M7.1 不执行训练、不导入日志、不生成指标；后续 Run 必须引用 frozen plan。

## 验证

`tests/integration/test_m7_experiment_repository.py` 覆盖 0011 升降级、批准算法门禁、冻结/拒绝、幂等保存和父版本历史。
