# ADR-0001：采用渐进式、证据优先的架构

- 状态：Accepted
- 日期：2026-08-09

## 背景

ScholarTrace 覆盖科研全生命周期。一次性创建全部模块会产生空壳接口、不可验证声明和难以审查的 Git 历史，也会让科研候选内容越过人工与证据门禁。

## 决策

- 严格按 M0 → M12 构建，每个里程碑先定义契约和测试，再实现与验收。
- `main` 始终可安装、可运行、可测试；M1 起每个里程碑使用独立功能分支。
- 早期使用单一主图与普通节点；只有上下文、权限或评测边界确实需要时才引入子 Agent。
- LLM 只产生候选；确定性工具负责解析、校验、计算和发布。
- State 只保存小型控制状态和实体 ID，大对象进入可追溯文件或对象存储。
- 所有正式产物遵循草案、校验、预览、人工确认、原子发布流程。

## 后果

优点是每个能力都有可复现证据、失败退化路径和清晰历史。代价是实现速度受门禁约束，且一些端到端能力要到后续里程碑才能出现。这一代价是有意接受的。
